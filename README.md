# 🎬 YouTube Tab Playlist Sorter

> Мощное расширение для **Zen Browser** (Gecko / Firefox), превращающее работу со множеством вкладок YouTube в удобный и быстрый процесс. Объединяйте вкладки в плейлисты, сортируйте видео по длительности с сохранением порядка на серверах YouTube и отслеживайте общее время воспроизведения на любой скорости.

## ✨ Основные возможности

### 1. 📑 Создание плейлистов из выделенных вкладок
Используйте встроенную функцию множественного выделения вкладок в Zen Browser (`Ctrl + клик` или `Shift + клик`):
* **⭐ Создание нового плейлиста в аккаунте:** Создает постоянный плейлист на вашем канале YouTube с выбранными настройками приватности (Приватный / По ссылке / Публичный).
* **🔄 Добавление в существующий плейлист:** Выберите любой открытый плейлист (аккаунтный или временный) и добавьте новые видео в него.
* **💾 Мгновенное сохранение временного плейлиста в аккаунт:** Переносит временный плейлист `watch_videos` в постоянный плейлист вашего аккаунта в один клик.
* **⚡ Временный плейлист (`watch_videos`):** Мгновенно запускает просмотр видео списком без авторизации и без засорения библиотеке аккаунта.

---

### 2. ⏱️ Сортировка по длительности
* **От коротких к длинным (▲):** Сначала короткие ролики, затем длинные подкасты и стримы.
* **От длинных к коротким (▼):** От самых масштабных видео к коротким.
* **Сохранение исходного порядка:** Объединение в порядке расположения вкладок.
* **Автоматическое закрытие вкладок:** Опционально закрывает обработанные вкладки после формирования плейлиста, освобождая оперативную память.

---

### 3. 🎯 Интерактивный виджет на странице плейлиста (`/playlist?list=...`)
Прямо в интерфейс плейлиста YouTube встраивается информационный блок:
* **Подсчет общего хронометража:** Мгновенный расчет суммарного времени всех роликов плейлиста.
* **Калькулятор скорости (0.25x – 16x):** Укажите скорость просмотра (или используйте быстрые пресеты `1x` и `2.5x`), и виджет мгновенно пересчитает реальное время, которое потребуется на просмотр.
* **Круглые кнопки сортировки (▲ / ▼):** Кнопки встроены под панель действий плейлиста.
* **Сохранение порядка на серверах YouTube:** При нажатии кнопки сортировки порядок видео не просто меняется в браузере, а **синхронизируется с аккаунтом YouTube через InnerTube API (`ACTION_MOVE_VIDEO_AFTER`)**. При нажатии «Воспроизвести» ролики запустятся в новом отсортированном порядке на любом устройстве!
* **Индикатор статуса:** Показывает текущее состояние операции (`⏳ Сохраняем...`, `✅ Порядок сохранён!`).

---

### 4. 📊 Виджет прогресса во время просмотра (`/watch?list=...`)
Во время воспроизведения плейлиста в панели справа отображается карточка прогресса:
* **Интерактивный прогресс-бар:** Наглядно показывает, какая часть плейлиста уже просмотрена.
* **Детальная статистика:** Просмотренное время, процент выполнения и оставшееся время до конца плейлиста.
* **Динамический пересчет по скорости:** Синхронизируется с текущей скоростью видео.
* **Плавная анимация и поддержка темы:** Идеально вписывается как в темную, так и в светлую тему YouTube.

## 📦 Быстрая установка в Zen Browser

### Вариант А: Постоянная установка из `.xpi` (Рекомендуется)

1. В адресной строке перейдите в настройки расширений:
   ```text
   about:config
   ```
2. Найдите параметр `xpinstall.signatures.required` и переключите его в значение `false`.
3. Перейдите на страницу дополнений:
   ```text
   about:addons
   ```
4. Нажмите на иконку шестерёнки ⚙️ в правом верхнем углу и выберите **«Установить дополнение из файла...»** (*Install Add-on From File...*).
5. Выберите готовый файл **`yt-tab-playlist.xpi`** из корня этого репозитория.
6. Подтвердите установку. Расширение зафиксировано и не будет слетать при перезапуске браузера!

---

### Вариант Б: Временная загрузка для разработки

1. В адресной строке откройте:
   ```text
   about:debugging#/runtime/this-firefox
   ```
2. Нажмите **«Загрузить временное дополнение...»** (*Load Temporary Add-on...*).
3. Выберите файл **`manifest.json`** в папке проекта.

## 🛠️ Архитектура и технологии

* **Движок:** Gecko / Firefox WebExtensions API (Manifest V3).
* **Firefox `wrappedJSObject`:** Прямой и безопасный доступ к свойствам компонентов YouTube Polymer (`setVideoId`) из изолированного контекста Content Script без нарушения CSP браузера.
* **YouTube InnerTube API:** Прямое взаимодействие с эндпоинтами:
  * `/youtubei/v1/playlist/create` — создание плейлистов;
  * `/youtubei/v1/browse/edit_playlist` — изменение состава и перестановка видео;
  * Авторизация через внутренний токен `SAPISIDHASH` текущей сессии YouTube.
* **Отказоустойчивость:** Защитные таймеры на мутации DOM, автоматическое снятие блокировок интерфейса при сетевых ошибках, поддержка SPA-навигации (`yt-navigate-finish`, `yt-page-data-updated`).
